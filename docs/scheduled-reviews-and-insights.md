# Scheduled Reviews and Workspace Insights

Laz Helper includes optional scheduled inbox reviews and local workspace summaries.

## Sloth Mode

Sloth Mode can review a designated folder on a configured interval. It is opt-in and disabled by default. A review summarizes files seen, items ready for review, uncertain items, and conflicts.

Sloth Mode does not move or delete files automatically. The scheduler runs within the application process, so scheduled checks occur only while Laz Helper is running.

## Workspace insights

Workspace insights summarize metadata such as file counts, extension distribution, folder distribution, total size, and largest files. These summaries are generated from file metadata and do not require sending file contents to an AI provider.

## Operating guidance

Choose an inbox that is inside the configured workspace. Keep the application running if scheduled reviews are required. Review the generated results before taking any file-changing action.
