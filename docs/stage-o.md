# Stage O — Navigation, responsive layout, and theme

- Adds a persistent in-page navigation for Home, Ask, Workspace, Tools, Permissions, and Plans.
- Adds a mobile menu with `aria-expanded`, Escape-to-close, click-away closing, and automatic closing after navigation.
- Adds System, Light, and Dark theme choices. The preference is stored locally in browser localStorage; System follows the existing CSS/default system preference.
- Adds a skip-to-content link, visible keyboard focus, semantic labels, and reduced-motion handling.
- No remote font, script, analytics, or theme service is introduced.
